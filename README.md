# Shahryar Pirooz — Personal Website

Modern personal portfolio built with Next.js, React, TypeScript and Tailwind CSS.

## Run locally

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Build

```bash
pnpm build
pnpm start
```

## Design

Dark-first interface using a blue → green gradient system, glass surfaces,
responsive layouts, subtle motion, and high-contrast typography.
